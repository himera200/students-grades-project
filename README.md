# StudentGrades

StudentGrades-консольнык приложения для учета оценок студентов

## Возможности

В проекте реализованы следующие основные возможности:
- регистрация пользователей (студентов, преподавателей, администраторов);
-авторизация в сиситеме;
- просмотр студентаими своих оценок, среднего балла и задолжностей;
- выставление и редактирование оценок преподавателями;
- просмотр академических ведомостей и формирование отчетов;
-управление пользователями, группами и предметами со стороны администратора.
